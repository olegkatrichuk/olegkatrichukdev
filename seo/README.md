# SEO assets (not part of the app build)

Off-site material to earn backlinks and corroborate the site's entity graph.
Nothing here is imported by Next.js — it's documentation + paste-ready content.

- **`backlink-playbook.md`** — the ordered plan. Start here. Checklist of
  where to place links, how to syndicate, what not to do.
- **`github-profile-README.md`** — paste into a public repo named `olegkatrichuk`
  to render a profile README with a high-authority backlink.
- **`crosspost/*.devto.md`** — journal posts with `canonical_url` set, ready to
  paste into dev.to / Hashnode. The canonical tag sends ranking signal back to
  olegkatrichuk.com and prevents duplicate-content issues.

## Quick start (one sitting)

1. Create repo `olegkatrichuk`, add the profile README → first backlink.
2. Add the site URL to LinkedIn, X, dev.to, Hashnode, Stack Overflow, DOU bios.
3. Paste both crosspost files into dev.to (set `published: true`), confirm the
   canonical points back. Repeat on Hashnode.
4. Google Search Console → validate the redirect fix, request indexing for
   `/en`, `/ru`, `/uk`.
